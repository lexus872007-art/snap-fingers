# Snap Fingers (Щёлк) - boss key for Windows

Snap your fingers - every window minimizes and the desktop is all that's left. Snap three times - everything comes back
exactly as it was. Works fully offline: the microphone listens only for the snap, nothing is recorded or sent anywhere.

**[Download for Windows](https://ty-biznesmen.ru/shchelchok)** - free, no sign-up. Windows 10/11, 64-bit.

![Snap Fingers](docs/snap-fingers.gif)

**See it in action (15 s):** https://youtube.com/shorts/6etfBuy2KOQ - two monitors, one snap.
More on the channel: https://youtube.com/@aleksey_ai_rabota

## What it does
- One snap - all windows go down, desktop is clean ("the boss is coming").
- Three snaps in a row - the same windows come back, in the same order.
- Works with the built-in laptop mic, a headset or headphones with a mic.
- No internet needed, ever. The last ~0.5 s of sound lives in memory only, for snap detection, and is discarded.
- Free updates: the app checks for a new version itself and installs it over the old one, settings stay.

## Set the sensitivity first
Snap Fingers learns *your* snap: open Settings, run **Snap setup** and snap a few times. If it reacts to knocks, typing or
colleagues talking, raise the **Threshold** a little - it only needs a sharp snap, not a loud one. One minute, and it
stops reacting to noise around you.

## Install
1. Download `Shchelchok-Setup.exe` from the [latest release](../../releases/latest) or from the site.
2. Run it. The installer downloads the program from our server and creates a shortcut.
3. Snap your fingers next to the mic. That's it.

If a download tool or proxy is on, turn it off for the download - some providers cut the connection.

## Privacy
No accounts, no telemetry, no network calls except the update check (one small text file on our server).

# Щёлк - «кнопка босса» для Windows

Щёлкнул пальцами - все окна свернулись, на экране только рабочий стол. Щёлкнул три раза подряд - всё вернулось как было.
Работает без интернета: микрофон слушает только щелчок, ничего не записывается и никуда не отправляется.

**[Скачать для Windows](https://ty-biznesmen.ru/shchelchok)** - бесплатно, без регистрации. Windows 10/11, 64 бит.

- Один щелчок - окна вниз. Три щелчка подряд - окна обратно, в том же порядке.
- Микрофон ноутбука, гарнитура или наушники с микрофоном.
- Обновления бесплатные: программа сама предлагает новую версию и ставит её поверх старой, настройки целы.

**Сначала настройте чувствительность под себя и шум вокруг.** В настройках есть «Настройка щелчка»: щёлкните несколько
раз, программа запомнит именно ваш щелчок. Если она срабатывает на стук, печать или разговоры коллег - чуть поднимите
«Порог». Важен резкий удар, а не громкость. Минута, и на посторонний шум она не реагирует.

Если включены «три буквы» - выключите их на время скачивания, часть провайдеров рвёт соединение.
